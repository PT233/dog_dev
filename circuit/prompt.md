请使用 KiCad MCP 在仓库根目录创建 circuit/ 工程，
设计一块用于桌面四足机器人项目的 STM32 Blue Pill 扩展板 PCB。
板子的本质是"Blue Pill 母座 + 全引脚面包板引出 + 4 路舵机插座 + MPU6050 预留位"。

请严格按照以下七节规范执行。每一节都是硬约束，不允许自由发挥。

═══════════════════════════════════════════════════
一、板层与板框
═══════════════════════════════════════════════════
- **2 层板**（不要 4 层），顶层信号 + 底层 GND 覆铜。
- 板框尺寸：80mm × 70mm（横向），四角倒圆 R2mm。
- 左下角为坐标原点 (0, 0)。
- 板子四角放 4 个 M3 安装孔：Φ3.2mm 钻孔 + Φ6mm 焊盘，
  距板边 4mm。
- 在 PCB 标题栏标注 "Quadruped Ext Board v1.0 / 2-Layer"。

═══════════════════════════════════════════════════
二、布局：STM32 居中放射状
═══════════════════════════════════════════════════
- **Blue Pill 必须放在板子几何中心**，使用两条 1×20 排母（2.54mm 间距），
  排母间距 17.78mm（700mil 标准 Blue Pill 宽度），长边沿板子长边。
- 排母 Pin1 一致朝向板子同一端（建议 USB 朝左）。
- 以 Blue Pill 为中心向四周辐射布局，五个分区：
    A. **左侧**：4 路 SG90 插座（FL/FR/RL/RR 上下排列），
       SIG 引脚朝向 Blue Pill（缩短走线）。
    B. **右侧**：面包板引出孔阵列（详见第三节）。
    C. **顶部**：舵机 5V 输入端子（KF301 2Pin，5.08mm 间距）+ 
       去耦电容（100nF + 470μF 电解）+ 单点共地焊盘。
    D. **底部**：MPU6050 预留 1×4 排母（2.54mm 间距）。
    E. **板边空白**：标题/版本/日期丝印。
- 元件最小间距 ≥ 1.5mm，功能相关元件聚拢成组。
- 所有元件放在顶层，**不使用底层放件**。

═══════════════════════════════════════════════════
三、面包板引出孔阵列（核心功能区）
═══════════════════════════════════════════════════
这是这块板子的核心扩展能力，必须完整实现：

- **Blue Pill 全部 40 个引脚都要引出**到外部面包板焊盘。
- 引出孔与对应排母引脚**同行平行排列**，放在排母外侧
  （右侧排母向右引出，左侧排母向左引出，左右对称）。
  → 这样用户插上 Blue Pill 后，目视即可对应每个 GPIO。
- 引出孔规格：Φ1.0mm 钻孔 + Φ1.8mm 焊盘，间距 2.54mm。
- 每排引出孔可选做成 2 列（共 80 个孔），增加面包板式插线灵活性。
- 排母焊盘到引出孔的走线**必须为直线或单折 90°**，
  长度尽量一致，视觉整齐。
- 引出走线全部走在顶层。

**不要**在引出孔旁标注 PA0/PB12 等引脚名（Blue Pill 自带丝印已有）。

═══════════════════════════════════════════════════
四、电气连接（参考 hardware_wiring.html）
═══════════════════════════════════════════════════
- PA0 → FL_SERVO SIG
- PA1 → FR_SERVO SIG
- PA2 → RL_SERVO SIG
- PA3 → RR_SERVO SIG
- PA9（TX）/ PA10（RX）：通过面包板引出孔可访问，无需专用接口。
- PB6（SCL）/ PB7（SDA）→ MPU6050 排母（也通过引出孔可访问）。
- 4 路 SG90 插座引脚顺序统一为 GND - 5V - SIG。
- 舵机 5V（5V_SERVO）和 MCU 5V（5V_MCU）**电源域隔离**，
  仅在一个明确标注的"单点共地"焊盘连接 GND，
  丝印标 "STAR GND"。
- 3V3 由 Blue Pill 提供，仅给 MPU6050 供电。

═══════════════════════════════════════════════════
五、丝印规则（避免与 Blue Pill 自带丝印冗余）
═══════════════════════════════════════════════════
板上**只标注**以下内容，其他一律不标：

1. Blue Pill 插入方向：在排母一端用三角箭头 + "USB →" 文字
   指明 USB 接口朝向。
2. 两条排母的 Pin1 实心三角标记。
3. SG90 插座：标 "FL" / "FR" / "RL" / "RR" + 一端标 "G-V-S"
   提示引脚顺序（不要逐脚标）。
4. 5V 输入端子：标 "5V_SERVO" + "GND"（粗体加方框）。
5. MPU6050 排母：标 "MPU6050" + "G V SCL SDA"。
6. 单点共地焊盘：标 "STAR GND"。
7. 板边标题：项目名 / 版本 / 日期 / "2-Layer"。

丝印规格：
- 字高 1.0mm，线宽 0.15mm。
- **严禁**压在焊盘、过孔、元件本体下。
- 放置完毕后开启 silk-to-pad / silk-to-silk DRC 检查，违规清零。

═══════════════════════════════════════════════════
六、走线规则（避免混乱）
═══════════════════════════════════════════════════
- 走线角度只允许 0° / 45° / 90°，禁止任意斜角。
- **任意一条走线最多 2 个折角**，超过则改路径或过孔到底层短跳。
- 走线与丝印文字、参考标号最小净距 ≥ 0.3mm。
- 非目标焊盘禁止被走线穿过。
- 过孔距焊盘边缘 ≥ 0.3mm。
- 走线宽度：
    - 信号 0.25mm
    - 一般电源（3V3、5V_MCU）0.5mm
    - 舵机主干 5V_SERVO 0.8mm
- 4 路 SG90 PWM 走线长度尽量一致，视觉对称。
- 底层整体 GND 覆铜，间距 0.3mm，热焊盘连接（spoke 4 辐），
  开启 "remove islands"，禁止孤岛铜区。
- 底层跳线不超过 5 条。
- 走线优先级：舵机 PWM → 电源 → I2C → UART → 其余引出。

七、自检与交付
═══════════════════════════════════════════════════
完成后**逐项执行并附详细结果**，不接受"已通过"一句话：

1. **ERC**：列出 error/warning 数量与每条详情，应为 0 错误。
2. **DRC**：clearance / silk-to-pad / silk-to-silk / courtyard / 
   hole-to-hole 全部检查，0 错误，列出检查项明细。
3. **走线折角统计**：直方图（0/1/2/>2 折角的走线条数），
   >2 折角的走线必须重新布线，不接受例外。
4. **连通性核对**：随机抽查 10 个 Blue Pill 引脚，
   确认对应引出孔有通路。
5. **PA0-PA3 → SG90 SIG** 一一对应核对。
6. **渲染图**：导出顶层 / 底层 / 丝印层 / 3D 视图各一张。
7. **关键指标**：板框尺寸、层数、过孔总数、最长走线长度、
   底层 GND 覆铜面积占比（应 > 70%）。
