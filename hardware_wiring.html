⚠️ 重要提醒 4 个 SG90 舵机必须使用独立的 5V 电源，不能从树莓派的 USB 供电！ 否则会导致树莓派重启或舵机无法正常动作。

通用接线规则

✓ 必须检查项
  • 所有地线必须连接：确保 PC、树莓派、STM32 的 GND 连接在同一网络
  • 电源隔离：舵机 5V 电源独立，逻辑 3.3V 从树莓派提供
  • UART 逻辑电平：树莓派输出 3.3V，STM32 输入 3.3V 兼容，但 STM32 输出 3.3V 也能被树莓派识别
  • I2C 上拉电阻：GPIO2(SDA) 和 GPIO3(SCL) 各需要 4.7kΩ 上拉到 3.3V
🔧 测试接线的方法
  • 使用万用表检查各引脚之间是否有短路（电阻应 > 100Ω）
  • 通电前用示波器验证 PWM 信号（PA0~PA3）是否存在
  • 使用 Python 脚本 `scripts/test_uart_rpi.py` 验证 UART 通信
  • 使用 `i2cdetect` 验证 MPU6050 是否被识别（地址 0x68）
